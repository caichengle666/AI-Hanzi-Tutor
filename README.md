# AI Hanzi Tutor（AI 全能识字助手）

给学龄前和小学低年级孩子用的家庭学习小应用：识字卡片、中文听写、英文听写、英文对话、AI 错题本。
打开网页就能用，可以“添加到主屏幕”像 App 一样使用；数据保存在本机，也可以用家庭同步码在手机和平板之间自动同步。

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| 🎴 识字卡片 | 田字格展示、笔顺动画、“写一写”描红、听读音、AI 讲解字义和组词、易混字辨析、AI 用生字讲故事、和“汉字”聊天、拍照加字 |
| 📝 听写练习 | 自动报词（可读多遍）、语音控制（喊“下一个”“重读”）、写完拍照让 AI 批改、错词自动收集、错词再练、听写历史 |

| 🔤 英文听写 | 单词、短句听写，拍照 AI 批改拼写，英文错词本 |
| 💬 英文对话 | AI 问简单英文问题，孩子说或打字回答，AI 判断并鼓励 |
| 📋 作业 | 为每个孩子建一份中文或英文听写作业，设为当前作业后进入练习 |
| 👨‍👩‍👧 多孩子 | 每个孩子独立的星星、词库、错题和记录 |
| ☁️ 云同步 | 填同一个家庭同步码，手机、平板数据互通（可选） |

## 家长上手：第一次使用（5 分钟）

### 第 1 步：打开网站

用 **Chrome / Edge / Safari** 打开你部署好的网址。

想像 App 一样用：
- **iPhone / iPad**：Safari 打开 → 底部“分享”按钮 → **添加到主屏幕**
- **安卓**：Chrome 打开 → 右上角菜单 → **添加到主屏幕 / 安装应用**

### 第 2 步：配置 AI（必做）

点右上角 **⚙️ 设置** → 找到 **AI 接口**：

**方式 A：OpenAI 兼容接口（国内推荐）**

1. 点 **OpenAI 兼容**
2. 填接口地址，例如 `https://api.openai.com/v1` 或你的中转站地址（以 `/v1` 结尾即可，会自动补全 `/chat/completions`）
3. 勾选 **通过本站代理请求**（推荐；中转站没开浏览器跨域也能用）
4. 填 **API Key**
5. 点 **拉取模型**，从下拉框里选一个模型（也可选“自定义模型”手动填）

**方式 B：Gemini**

1. 点 **Gemini**
2. 填 Gemini API Key（可在 [Google AI Studio](https://aistudio.google.com/) 申请）
3. 选模型
> ⚠️ Gemini 模式是浏览器直连 Google，国内网络用不了，请用方式 A。

**测试一下**：点 **测试文字**、**测试图片**，都显示“测试通过”再给孩子用。
“测试图片”通过后，拍照加字、拍照批改、拍照录错题才能正常工作。

最后点页面底部的 **保存设置**。

> AI Key 只保存在这台设备的浏览器里，**每台设备都要各自填一次**（同步码不会同步 Key）。

### 第 3 步：添加孩子

设置 → **孩子档案** → **新增**，输入名字。可以建多个，首页顶部点名字即可切换。

### 第 4 步：选择朗读声音（建议）

设置 → **中文语音** / **英文语音**，下拉选一个声音会立刻试读。
- 推荐选带 **[本地]** 的声音，离线也能读、反应快
- 列表是空的？展开下面的“还没有找到声音”，按提示到系统设置里下载语音包

### 第 5 步（可选）：开启云同步

家里有多台设备时，见下方 [多设备同步与备份](#多设备同步与备份)。

### 第 6 步（可选）：学习提醒

设置 → **学习提醒** → 勾选“打开应用时提醒学习”，设置时间和提醒内容。

## 日常使用：各个模块怎么用

### 🎴 识字卡片

1. 首页点 **识字卡片**
2. 添加生字，三种方式任选：
   - **手动/批量**：一次输入多个汉字，例如“天地人你我他”
   - **拍照加字**：拍课本或生字卡，AI 自动识别汉字加入生字本
   - 从作业带入
3. 点一个字进入学习：
   - **听读音**：朗读这个字
   - **写一写**：跟着笔顺描红
   - **AI讲解**：用孩子听得懂的话讲意思、组词、成语
   - **聊聊天**：和这个“汉字”对话
   - 拼音不对可以用 **拼音修正**
4. **AI 创意绘本**：把最近学的生字编成小故事，可 **朗读故事**
5. 学会后点 **完成** 得星星 ⭐

### 📝 中文听写

1. 首页点 **听写练习**，先在词库里添加要听写的词（可手动编辑，也可拍课本生字表导入）
2. 点 **▶ 开始**，应用自动报词；孩子在纸上写
   - **↺ 重读**：再读一遍
   - **下一个 ⏭**：读下一个词
   - 语音控制：直接喊“下一个”“重读”“看一眼”（Chrome 效果最好；iOS 不灵时先拍一下屏幕再喊）
   - “看一眼”只短暂显示答案 1～3 秒
3. 听写完拍照上传，点 **批改**，AI 逐个判断对错
4. 有疑问的显示为 **待确认**，家长可以改成正确/错误
5. 点 **加入错题** 把错词收进错词本；之后用 **错词再练** 专门复习
6. **听写总结** 里可以看历史记录、导出、清空

### 📒 错题本

1. 首页点 **错题本**
2. 拍照录入错题（支持数学等各科），AI 整理出题目、孩子的错答、正确答案和错因，确认后点 **保存选中错题**
3. 点一道错题可以：
   - 看 **为什么错**、**解析**、**小窍门**
   - **播放讲解** / **播放故事讲解**：让孩子听懂
   - **再练一道** / **再练3道**：AI 出同类题举一反三
   - 孩子答完点 **做对了** 或 **还需练**
4. 首页“待复习错题”会按复习计划提醒；在错题本里选 **今日 5 题 / 今日 10 题** 开始当天复习
5. 家长可以按学科、状态、日期筛选，看 **高频错误**，并 **导出 Markdown / TXT / 打印 PDF**

### 🔤 英文听写

1. 首页点 **英文听写** → **编辑词库** 添加单词或短句
2. 孩子听英文（可 **重听**），在纸上写，写完拍照，AI 批改拼写
3. 错的进入英文错词本，用 **错词再练** 复习

### 💬 英文对话

1. 首页点 **英文对话** → **开始英文对话**
2. AI 问一个简单英文问题（可 **播放问题**），孩子用语音或打字回答
3. 点 **AI 判断回答** 得到反馈；点 **新问题** 继续；**对话记录** 里可回看

### 📋 作业

首页点 **作业** → **新建作业**（中文或英文听写）→ **保存并设为当前作业**，之后进入对应模块就会用这份作业的内容练习。

## 多设备同步与备份

### 云同步（推荐给多设备家庭）

1. 在第一台设备：设置 → **云同步** → 填一个**家庭同步码**（至少 8 位，越长越安全）→ **立即同步**
2. 在其他设备：同样填**同一个同步码** → **立即同步**
3. 之后会自动同步：
   - 打开应用时先拉取云端数据
   - 每次学习保存后约 2.5 秒自动上传
   - 回到首页、切回应用时再拉取一次（听写进行中不会打断）
   - 失败时顶栏会出现“同步失败，重试”

同步内容：孩子档案、星星、生字本、听写词库和记录、英文词库、错题本、学习提醒。
**不同步**：AI Key、语音选择（这些跟设备有关，每台设备单独设置）。

注意：
- 同步码就是你家数据的钥匙，不要告诉别人；服务器上只保存它的哈希值
- 按“每个孩子一整份”同步，以**最后保存的设备为准**。尽量不要两台设备同时给同一个孩子学习
- 清空同步码并点“立即同步”即关闭云同步，数据回到只存本机

### 手动备份 / 迁移

设置 → 孩子档案：
- **完整学习备份**：把当前孩子的全部数据下载为一个 JSON 文件
- **导入完整备份**：选择 JSON 文件恢复到当前孩子（会替换当前孩子的全部数据，导入前会提示内容摘要）

建议换手机、清浏览器数据之前先做一次备份。

## 部署到 Cloudflare（自己搭一份）

项目以 **Cloudflare Worker** 形式部署：Worker 同时提供网页静态文件、`/api/llm` 同源代理和 `/api/sync` 云同步接口。推送到 `main` 分支后由 GitHub Actions 自动部署。

### 第 1 步：Fork 或克隆仓库

```bash
git clone https://github.com/caichengle666/AI-Hanzi-Tutor.git
```

### 第 2 步：改成你自己的 Cloudflare 账号

编辑 `wrangler.jsonc`：

```jsonc
{
  "name": "damp-tree-d795",            // Worker 名字，可改成你喜欢的
  "account_id": "你的 Cloudflare 账号 ID", // 控制台右侧栏 / 账户首页可以看到
  ...
  "d1_databases": [
    { "binding": "DB", "database_name": "ai-hanzi-tutor-sync" } // 不用填 database_id
  ]
}
```

D1 数据库**不需要手动创建**：第一次部署时 wrangler 会按这个配置自动建库并绑定，表结构由 Worker 在第一次请求时自动创建。

### 第 3 步：创建 Cloudflare API Token

Cloudflare 控制台 → 右上角头像 → **我的个人资料 → API 令牌 → 创建令牌**，用“编辑 Cloudflare Workers”模板，并确认包含：

- 账户 → **Workers 脚本：编辑**
- 账户 → **D1：编辑**（云同步建库需要，缺了首次部署会失败）

### 第 4 步：把 Token 填到 GitHub

GitHub 仓库 → **Settings → Secrets and variables → Actions → New repository secret**：

- Name：`CLOUDFLARE_API_TOKEN`
- Value：上一步生成的 Token

### 第 5 步：部署

推送到 `main` 分支即可自动部署（也可以在 **Actions → Deploy to Cloudflare → Run workflow** 手动触发）。
部署成功后，在 Cloudflare 控制台 → Workers 里能看到访问地址（`*.workers.dev`），也可以绑定自己的域名。

### 手动部署（不用 GitHub Actions）

```bash
npm install
npm run build
npx wrangler login
npx wrangler deploy
```

## 常见问题

**测试文字失败：“网络错误 / 被浏览器跨域拦截”**
用的是 OpenAI 兼容接口时，勾选“通过本站代理请求”。注意本地 `npm run dev` 没有代理，要用部署后的网址或 `wrangler dev`。

**Gemini 一直连不上**
国内网络无法直连 Google，改用 OpenAI 兼容接口 + 中转地址。

**拍照批改 / 拍照加字没反应**
先在设置里点“测试图片”。不通过说明当前模型不支持图片，换一个支持视觉的模型（如 gpt-4o、gpt-4o-mini、gemini 系列）。

**没有声音或声音很怪**
到设置里手动选一个中文/英文声音，优先选 [本地]；按页面里的提示下载系统语音包。iPhone 请先关闭静音键。

**语音控制（喊“下一个”）不灵**
依赖浏览器的语音识别，Chrome/Edge 效果最好；iOS Safari 受系统限制，需要先点一下屏幕。

**云同步显示“缺少家庭同步码”或“同步失败”**
检查同步码是否至少 8 位、各设备是否完全一致（区分大小写）；网络恢复后点顶栏“同步失败，重试”。

**云同步提示“服务器还没有绑定 D1 数据库”**
用最新代码重新部署一次，并确认 API Token 有 D1 编辑权限。

**更新后页面还是旧的**
关闭应用重新打开，或在浏览器里强制刷新一次。

## 技术栈与目录结构

- 前端：React 18 + Vite 5 + Tailwind CSS 3
- 汉字笔顺：Hanzi Writer
- AI：OpenAI 兼容接口 / Google Gemini（Key 由家长在设备上填写）
- 语音：Web Speech API（朗读 + 识别），ResponsiveVoice 兜底
- 本地存储：IndexedDB（孩子数据）+ localStorage（设置）
- 后端：Cloudflare Worker + D1（同源代理、云同步）
- 测试：Vitest

```
├── src/
│   ├── App.jsx                  # 路由、孩子档案、云同步调度
│   ├── components/              # 各页面：首页、识字、听写、错题本、英文、作业、设置
│   ├── hooks/                   # 语音、屏幕常亮、本地存储
│   └── lib/
│       ├── llm.js               # AI 调用（直连 / 本站代理）
│       ├── childWorkspace.js    # 每个孩子的数据（IndexedDB）
│       ├── cloudSync.js         # D1 云同步客户端
│       ├── childData.js         # 备份导入导出
│       └── reviewNotebook.js    # 错题本与复习计划
├── worker/index.js              # Cloudflare Worker：/api/llm 代理、/api/sync 云同步、静态资源
├── public/                      # PWA manifest、Service Worker、图标
├── wrangler.jsonc               # Worker 与 D1 配置
└── .github/workflows/           # 推送 main 自动部署
```
